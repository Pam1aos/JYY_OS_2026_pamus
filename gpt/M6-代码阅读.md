# M6: GPT-2 推理 —— `gpt.c` 代码阅读

> 框架代码：`git pull origin M6` 得到的 `gpt/` 目录
> 模型文件：`gpt2_124M.bin`（约 500MB，需手动下载到 `gpt/`，不进 git）
> 本文目标：读懂 `gpt.c` 在算什么、数据怎么流动，不涉及并行化改造

---

## 0. 一句话理解

> 输入一串整数 token，模型输出“下一个 token 的概率分布”，采样一个接回序列，再重复，直到凑满 10 个 token。

```
[31373, 612]  ──►  GPT-2  ──►  P(next token)  ──►  采样 852
                                                       │
[31373, 612, 852]  ◄──────────────────────────────────┘
        │
        └──► 再算下一个 ...
```

模型不认识文字，只认识整数。`chat.py` 负责用 `tiktoken` 在文本和 token 之间转换。

## 2. 整体算法流程

```
 文本 "Ladies and"
      │
      ▼  chat.py / tiktoken
 [31373, 612]
      │
      ▼
┌──────────────────────────────────────────────────────────────┐
│                        GPT-2 前向传播                         │
│                                                              │
│  token ids ──► Embedding ──► [Transformer × 12] ──► Logits   │
│                                                              │
│  每个位置输出一个 V=50257 维的“下一个 token 得分”             │
└──────────────────────────────────────────────────────────────┘
      │
      ▼
  softmax → 概率分布
      │
      ▼
  采样（coin = 0.5 的中位数采样）
      │
      ▼
  新 token 852
      │
      ▼
  追加到输入，重复，直到 10 个 token
```

### 程序执行流程

```
main()
 │
 ├─ gpt2_build_from_checkpoint("gpt2_124M.bin")
 │      读 header → 分配参数 → 读入 500MB 权重
 │
 ├─ 把 argv 里的 token 填进 tokens[]
 │
 └─ for t = 输入长度 .. 9:
        │
        ├─ gpt2_forward(tokens, B=1, T=t)
        │      │
        │      ├─ encoder_forward
        │      ├─ 12 × transformer block
        │      ├─ final LayerNorm
        │      ├─ logits = lnf × wteᵀ
        │      └─ softmax
        │
        ├─ 取最后一个位置的概率 probs[t-1]
        ├─ next = sample_mult(probs, V)
        ├─ tokens[t] = next
        └─ 打印 next
```

## 3. 数据表示

### 3.1 维度符号

| 符号 | 含义 | GPT-2 124M |
|---|---|---|
| `B` | batch size | 本实验恒为 1 |
| `T` | 当前序列长度 | 2 ~ 10 |
| `C` | 通道数 / embedding 维度 | 768 |
| `V` | 词表大小 | 50257 |
| `L` | Transformer 层数 | 12 |
| `NH` | 注意力头数 | 12 |
| `hs` | 每个头的维度 = C / NH | 64 |

### 3.2 内存布局

所有张量都是扁平的 `float` 数组，用指针算术模拟多维：

```c
x[b][t][c]  →  x + b*T*C + t*C + c
```

例如：

```c
float* x = inp + b * T * C + t * C;   // 第 (b,t) 个位置的 C 维向量
```

### 3.3 参数张量（`ParameterTensors`，gpt.c:233）

| 字段 | 形状 | 作用 |
|---|---|---|
| `wte` | `(V, C)` | token embedding 表 |
| `wpe` | `(maxT, C)` | 位置 embedding 表 |
| `ln1w/ln1b` | `(L, C)` | 第一个 LayerNorm 的缩放/平移 |
| `qkvw/qkvb` | `(L, 3C, C)` / `(L, 3C)` | QKV 投影 |
| `attprojw/attprojb` | `(L, C, C)` / `(L, C)` | attention 输出投影 |
| `ln2w/ln2b` | `(L, C)` | 第二个 LayerNorm |
| `fcw/fcb` | `(L, 4C, C)` / `(L, 4C)` | MLP 升维 |
| `fcprojw/fcprojb` | `(L, C, 4C)` / `(L, C)` | MLP 降维 |
| `lnfw/lnfb` | `(C)` | 最终 LayerNorm |

`malloc_and_point_parameters()` 一次性分配所有参数，再把每个指针指向大数组的不同偏移。

### 3.4 激活张量（`ActivationTensors`，gpt.c:275）

| 字段 | 形状 | 说明 |
|---|---|---|
| `encoded` | `(B,T,C)` | embedding 输出 |
| `ln1` | `(L,B,T,C)` | 每层 LN1 输出 |
| `qkv` | `(L,B,T,3C)` | Q、K、V 拼接 |
| `preatt` / `att` | `(L,B,NH,T,T)` | 注意力原始分数 / softmax 后权重 |
| `atty` | `(L,B,T,C)` | attention 输出 |
| `attproj` | `(L,B,T,C)` | attention 输出投影 |
| `residual2` | `(L,B,T,C)` | attention 后的残差 |
| `ln2` | `(L,B,T,C)` | LN2 输出 |
| `fch` / `fch_gelu` | `(L,B,T,4C)` | MLP 中间结果 |
| `fcproj` | `(L,B,T,C)` | MLP 降维结果 |
| `residual3` | `(L,B,T,C)` | MLP 后的残差（下一层输入） |
| `lnf` | `(B,T,C)` | 最终 LayerNorm |
| `logits` / `probs` | `(B,T,V)` | 词表得分 / 概率 |

## 5. 前向传播总流程

`gpt2_forward()`（gpt.c:419）：

```
tokens (B,T) : int
      │
      ▼
┌─────────────────────────┐
│ encoder_forward         │  wte[token] + wpe[pos]
└─────────────────────────┘
      │
      ▼
encoded (B,T,C)  ── 作为第 0 层的 residual
      │
      ▼
┌───────────────────────────────────────────────────────────────┐
│ for l = 0 .. L-1                                              │
│                                                               │
│  residual ──► LN1 ──► QKV MatMul ──► Attention ──► AttnProj   │
│       │                                              │        │
│       └──────────────── (+) ◄────────────────────────┘        │
│                            │                                  │
│                            ▼ residual2                        │
│  residual2 ──► LN2 ──► FC MatMul ──► GELU ──► FCProj          │
│       │                                          │            │
│       └────────────────── (+) ◄──────────────────┘            │
│                          │                                    │
│                          ▼ residual3  ──► 下一层 residual      │
└───────────────────────────────────────────────────────────────┘
      │
      ▼
final LayerNorm
      │
      ▼
logits = lnf × wteᵀ   (B,T,V)
      │
      ▼
softmax
      │
      ▼
probs (B,T,V)
```

### 张量形状流

```text
tokens           (1, T)
encoded          (1, T, 768)
ln1              (1, T, 768)
qkv              (1, T, 2304)      = 3C
preatt / att     (1, 12, T, T)     = NH
atty             (1, T, 768)
attproj          (1, T, 768)
residual2        (1, T, 768)
ln2              (1, T, 768)
fch              (1, T, 3072)      = 4C
fch_gelu         (1, T, 3072)
fcproj           (1, T, 768)
residual3        (1, T, 768)
lnf              (1, T, 768)
logits           (1, T, 50257)     = V
probs            (1, T, 50257)
```

### 对应的数学形式

```text
X₀   = WTE[token] + WPE[pos]                      # embedding
X'   = X + Attn(LN1(X))                           # 注意力子层
X''  = X' + MLP(LN2(X'))                          # MLP 子层
logits = LNf(X'') · WTEᵀ                          # 输出投影（weight tying）
probs  = softmax(logits)
```

## 6. 逐算子算法流程

### 6.1 `encoder_forward`（gpt.c:19）

```
for b in 0..B-1:
  for t in 0..T-1:
     ix = inp[b,t]                    # token id
     wte_ix = wte + ix*C              # 该 token 的向量
     wpe_t  = wpe + t*C               # 该位置的向量
     out[b,t,:] = wte_ix + wpe_t      # 逐元素相加
```

```
 token id ix ──► wte 第 ix 行 ──┐
                                ├──► 逐元素相加 ──► encoded[b,t,:]
 位置 t      ──► wpe 第 t 行  ──┘
```

- 纯查表 + 加法；
- 每个位置独立；
- 复杂度 `O(B·T·C)`。

### 6.2 `layernorm_forward`（gpt.c:44）

对每个 `(b,t)` 的 C 维向量 `x`：

```
          x (C)
           │
           ▼
     m = Σ x[i] / C                （均值）
           │
           ▼
     v = Σ (x[i]-m)² / C           （方差）
           │
           ▼
     s = 1 / sqrt(v + eps)         （标准差的倒数）
           │
           ▼
     out[i] = s · (x[i]-m) · w[i] + b[i]
```

- `eps = 1e-5`，防止除零；
- `w`、`b` 是该层可学习的缩放和平移；
- 每个位置独立，复杂度 `O(B·T·C)`。

### 6.3 `matmul_forward`（gpt.c:86）

```
out[b,t,o] = bias[o] + Σ_i inp[b,t,i] · weight[o,i]
```

```
                 weight (OC, C)
                 第 o 行 ─────────┐
                                  ▼
inp[b,t,:] (C) ───────────────► 点积 ──► + bias[o] ──► out[b,t,o]
                                  ▲
                         对 o = 0..OC-1 重复
```

- 三重循环：`B × T × OC × C`；
- 每层出现 4 次：
  - QKV 投影：`OC = 3C`
  - attention 输出投影：`OC = C`
  - MLP 升维：`OC = 4C`
  - MLP 降维：`OC = C`
- 最后一层：`OC = V = 50257`，最重。

### 6.4 `attention_forward`（gpt.c:109）

输入 `qkv (B,T,3C)` 按通道切分：

```
qkv[b,t,:] = [ Q (C) | K (C) | V (C) ]
              0..C     C..2C    2C..3C
```

每个 `(b,t,h)`，`hs = C/NH`：

```
Q_h = Q[t, h*hs .. (h+1)*hs]
       │
       ▼
 for t2 = 0 .. t:                       # 因果：只能看过去
       score[t2] = (Q_h · K_h(t2)) / sqrt(hs)
       │
       ▼
 m = max(score[0..t])
       │
       ▼
 e[t2] = exp(score[t2] - m)             # 数值稳定
       │
       ▼
 att[t2] = e[t2] / Σ e                  # softmax
       │
       ▼
 out[t,h] = Σ_{t2<=t} att[t2] · V_h(t2)  # 加权求和
```

#### 因果 mask

```text
        t2=0  1  2  3
 t=0      ✓
 t=1      ✓  ✓
 t=2      ✓  ✓  ✓
 t=3      ✓  ✓  ✓  ✓
```

- 上三角（未来位置）不参与；
- 代码里把 `t2 > t` 的 `att` 显式置 0；
- 只有 attention 会跨时间位置混合信息，其余算子都是逐位置独立。

复杂度 `O(B·NH·T²·hs) = O(B·T²·C)`。

### 6.5 `gelu_forward`（gpt.c:185）

逐元素：

```
        x
        │
        ▼
   cube = 0.044715 · x³
        │
        ▼
   tanh( sqrt(2/π) · (x + cube) )
        │
        ▼
   out = 0.5 · x · (1 + tanh(...))
```

- 平滑的非线性函数；
- 给 MLP 提供表达能力。

### 6.6 `residual_forward`（gpt.c:194）

```
out[i] = inp1[i] + inp2[i]
```

```
   输入 x ────────────────┐
                          ▼
   子层输出 f(x) ───────► (+) ──► x + f(x)
```

### 6.7 `softmax_forward`（gpt.c:200）

对每个 `(b,t)` 的 V 维向量：

```
logits (V)
   │
   ▼
 m = max(logits)                       # 数值稳定
   │
   ▼
 p[i] = exp(logits[i] - m)
   │
   ▼
 sum = Σ p[i]
   │
   ▼
 probs[i] = p[i] / sum
```

### 6.8 最后一层投影与 weight tying

```c
matmul_forward(acts.logits, acts.lnf, params.wte, NULL, B, T, C, V);
```

- 用 `wte (V,C)` 作为输出投影矩阵；
- 输出 `logits (B,T,V)`；
- 没有 bias；
- 这叫 weight tying：输入 embedding 和输出投影共享权重。

### 6.9 采样：`sample_mult`（gpt.c:549）

```c
float cdf = 0.0f, coin = 0.5f;
for (int i = 0; i < n; i++) {
    cdf += probabilities[i];
    if (coin < cdf)
        return i;
}
```

```
probs:  [0.05 | 0.10 | 0.40 | 0.45]
cdf:     0.05   0.15   0.55   1.00
coin:    0.5 ────────────▲
                          └── 返回 index 2
```

- 固定 `coin = 0.5`，即“累积概率刚好超过 0.5 的 token”；
- 结果确定，不依赖随机数。

## 8. 自回归生成的完整时序

`main()`（gpt.c:565）里 `n = 10`：

```c
for (int t = argc - 1; t < n; t++) {
    gpt2_forward(&model, tokens, 1, t);
    float* probs = model.acts.probs + (t-1) * V;
    tokens[t] = sample_mult(probs, V);
    printf("%d\n", tokens[t]);
}
```

### 以测试输入为例

测试 token：`31373 612 338 635 281 4998 3715 351 2506`（9 个）

```text
初始：
 tokens[0..8] = 输入 token
 tokens[9]    = GPT2_EOT（占位）

t = 9：
 ┌─────────────────────────────────────────────┐
 │ forward(T=9)                                │
 │ tokens[0..8] → ... → probs[8]               │
 └─────────────────────────────────────────────┘
                │
                ▼
        sample(probs[8]) = 852
                │
                ▼
        tokens[9] = 852
        打印 852
```

> 测试只需要输出中包含 `852`，所以只跑一次前向。

### 一般输入（k 个 token）

```text
第 1 轮  T=k    : forward(tokens[0..k-1])   → 预测 tokens[k]
第 2 轮  T=k+1  : forward(tokens[0..k])     → 预测 tokens[k+1]
...
第 n-k 轮 T=n   : forward(tokens[0..n-1])   → 预测 tokens[n]
```

每轮都重新计算整个前缀，计算量随 `T` 增长。

## 9. 计算量与热点

每层、每个 token 的主要矩阵乘法（MACs）：

| 操作 | MACs |
|---|---|
| QKV 投影 | `3C²` |
| attention 输出投影 | `C²` |
| MLP 升维 | `4C²` |
| MLP 降维 | `4C²` |
| 合计 | `≈ 12C²` |

`C = 768`：

```text
每 token 每层 ≈ 7.1M MACs
12 层         ≈ 85M MACs / token
最后 logits   ≈ T × 38.6M MACs
```

`T = 9` 时，最后 `logits` 约 347M MACs，占整体约 1/3。

### 结论

- **矩阵乘法是绝对热点**，尤其是最后映射到词表的 `logits`；
- attention 的 `T²` 项在 `T ≤ 10` 时很小；
- LayerNorm / GELU / residual / softmax 计算量小，但仍然是算法的一部分；
- 用 `perf record` / `perf report` 可以验证热点。

## 13. 一句话总结

> `gpt.c` 是“token → embedding → 12 层 Transformer → logits → softmax → 采样”的朴素实现。
> 每一层由「LayerNorm → 注意力 → 残差 → LayerNorm → MLP → 残差」组成，只有注意力跨时间位置混合信息，其余算子逐位置独立；最后的 `logits` 投影（`C → V`）是计算量最大的单步。
